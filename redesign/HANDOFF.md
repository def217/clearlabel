A full visual rebuild of the clearlabel.eu homepage, specified to read like a printed
standards-body notice rather than a SaaS landing page. Generated by DeepSeek flash against
`prompt.txt`, in three calls (a single call exhausts its token budget on hidden reasoning).

No gradients · no box-shadows · no banned fonts (Inter/Roboto/Poppins/Montserrat/Arial) · no emoji ·

## The job

Integrate into the live homepage **without breaking the working scanner**.

1. `index.html` is live and currently works. Build the new page beside it first, do not overwrite.
2. The scanner is real and must be preserved exactly. `app.js` imports `scanHtml` and `assess`
   from `scanner/core.mjs`, fetches through a CORS reader chain (`r.jina.ai` first, with the
   `x-respond-with: html` header — without that header it returns markdown and silently strips
   the `<script>` tags the fingerprints live in), and produces:
   `{ url, vendors[], disclosures[], contentSignals[], pagesRead[], overall, findings[] }`
3. Rewire `app.js` DOM writes to the new hook points: `#scan-form #scan-url #scan-submit
   #scan-phase #check-vendor #check-disclosure #check-marking #scan-result`.
4. Keep every current behaviour: user-initiated multi-page fallback (NOT automatic — automatic
   4x fetching hits the shared free-proxy rate limit), the free disclosure-wording sample,
   `STORE_LIVE` gating the Gumroad CTA, and the Cloudflare Web Analytics beacon.
5. Fonts: spec asks for IBM Plex from Google Fonts. **Self-host them instead**, as the current site
   does — a Munich court held that embedding Google Fonts leaks visitor IPs in breach of GDPR, and
   this is an EU compliance site. See `fonts.css` and `fonts/` for the existing pattern.

## Numbers must stay frame-accurate

The spec's stats row says 97% / 0.4% / 703 / 36. Correct usage:
- **97%** = e-commerce frame only (180 scanned / 135 readable). Must be labelled "online shops".
- **0.4%** = combined marking figure. 
- **703** = Tranco frame scanned. The **full corpus is 883**; 667 readable.
- **36** = vendors in `data/vendors.json`.
Combined figures live in `study/summary-combined.json`. Never attach a per-frame stat to the total —
that bug was already fixed once (69% off-homepage is Tranco-only; combined is 37%).
